1. PROPÒSIT DEL PROJECTE I ARQUITECTURA GENERAL
-------------------------------------------------------------------------------
CoupleForms és una canalització d'automatització d'extrem a extrem (End-to-End Content Pipeline) desenvolupada en Python 3.10 i integrada amb GitHub Actions. 

El seu objectiu és la generació automàtica i publicació de contingut de doble format enfocat al nínxol de parelles ("Couples") per a Instagram i TikTok, dirigint el tràfic cap a la plataforma web `formfriends.com`:

1. Carrousels d'Imatges (1080x1080, 6 slides): Estil retro 35mm amb preguntes profundes i tests de parella.
2. Vídeos / Reels / TikToks (1080x1920, 9:16): Fons de paisatge d'estoc en moviment amb un marc quadrat retro centrat (1080x1080) i contingut dinàmic (frases, carrousels de preguntes, tests A/B, POVs i checklists).

3. CANALITZACIÓ 1: CARROUSELS D'IMATGES (generate_and_send_couples.py)
-------------------------------------------------------------------------------
- Canvas: 1080 x 1080 píxels (Format quadrat 1:1), JPEG qualitat=95.
- Estructura: 6 diapositives (Portada + 5 preguntes o enunciats de test).
- Fons: Generat via Google AI Studio (Imagen 3: `imagen-3.0-generate-002`) o Unsplash High-Res API com a fallback.
- Filtre Retro 35mm: Baixada de contrast (0.85), transformació de matriu de color vintage (Sepia càlid) i foscor (0.42) amb marc negre exterior arrodonit (radi=60, margin=28) integrat per màscara de difuminat (blur_r=10).
- Fonts: Playfair Display per als títols/preguntes i Poppins Medium per al footer (`coupleforms`).
- Font de dades: Intercala automàticament entre `posts.csv` i `posts_test.csv` registrant l'estat a `next_post_type.txt`.

-------------------------------------------------------------------------------
4. CANALITZACIÓ 2: VÍDEOS / REELS / TIKTOKS (generate_and_send_reels.py)
-------------------------------------------------------------------------------
- Canvas de vídeo: 1080 x 1920 píxels (Format vertical 9:16), H.264 MP4 a 24 fps.
- Estètica del marc: Manté l'estil quadrat retro centrat verticalment (1080x1080 d'Y=420 a Y=1500) amb barres fosques superiors/inferiors per mantenir la coherència visual amb els posts.
- Font de Vídeo de Fons: Pexels Video API (`https://api.pexels.com/videos/search`), descarregant vídeos d'estoc HD verticals de paisatges naturals sense marca d'aigua (`PEXELS_API_KEY`).
- Engine de Renderització: PIL (Pillow) genera capes PNG transparents amb el marc retro i el text. Posteriorment, **MoviePy** ensambla les capes PNG sobre el vídeo de Pexels utilitzant `CompositeVideoClip`. Això s'executa sense necessitat d'ImageMagick.

Tipus de Reels suportats (Rotació automàtica o selecció via `FORCE_TYPE`):
1. `type1` (video_phrases.csv): Frase d'amor central única (8 segons).
2. `type2` (video_questions.csv): Carousel de 3 preguntes seqüencials (14 segons).
3. `type3` (video_tests.csv): Test A/B ràpid amb títol, pregunta i dues opcions (9 segons).
4. `type4` (video_povs.csv): POV o nota poètica de 3 línies acumulatives (10 segons).
5. `type5` (video_checklists.csv): Checklist de 4 punts que es van marcant (12 segons).

-------------------------------------------------------------------------------
5. MODES D'EXECUCIÓ, TEST MODE I TELEGRAM INTEGRATION
-------------------------------------------------------------------------------
Tots dos scripts incorporen la variable global `TEST_MODE`:

- Si `TEST_MODE = True`:
  - S'omet la publicació a la xarxa social via Buffer.
  - S'envia el contingut directament a Telegram via Telegram Bot API per a la seva revisió:
    - Carrousels: Envia l'àlbum de les 6 diapositives via `sendMediaGroup`.
    - Reels: Envia el fitxer de vídeo `.mp4` via `sendVideo`.
  - Es marca la fila com a 'Done' al CSV i es fa commit/push automàtic a Git per mantenir la persistència de dades.

- Si `TEST_MODE = False`:
  - Publica automàticament a través de Buffer GraphQL API.
  - Envia confirmació i còpia del mitjà a Telegram.
  - Actualitza el CSV i fa commit/push a Git.

6. VARIABLES D'ENTORN I SECRETS DE GITHUB
-------------------------------------------------------------------------------
- `PEXELS_API_KEY`: Clau d'API de Pexels per a la descàrrega de vídeos de fons.
- `TELEGRAM_BOT_TOKEN`: Token del bot de Telegram.
- `TELEGRAM_CHAT_ID`: ID del xat/canal de Telegram on es reben les proves/revisions.
- `GEMINI_API_KEY`: Clau de Google AI Studio per a la generació d'imatges via Imagen 3.
- `BUFFER_ACCESS_TOKEN`: Token d'accés de Buffer per a la publicació automàtica.
- `GITHUB_TOKEN`: Proporcionat automàticament per GitHub Actions (`permissions: contents: write`).
