1. PROPÒSIT DEL PROJECTE I ARQUITECTURA GENERAL
-------------------------------------------------------------------------------
CoupleForms és una canalització d'automatització d'extrem a extrem (End-to-End Content Pipeline) desenvolupada en Python 3.10 i integrada amb GitHub Actions. 

El seu objectiu és la generació automàtica i publicació de contingut de doble format enfocat al nínxol de parelles ("Couples") per a Instagram i TikTok, dirigint el tràfic cap a la plataforma web `formfriends.com`:

1. Carrousels d'Imatges (1080x1080, 6 slides): Estil retro 35mm amb preguntes profundes i tests de parella (100 registres a `posts.csv` i `posts_test.csv`).
2. Vídeos / Reels / TikToks (1080x1920, 9:16): Fons de paisatges naturals HD de Pexels, canviant cada ~4s amb transicions de fosa a negre, un marc quadrat retro centrat (1080x1080 a Y=420), contingut dinàmic llegible amb ombra de text i **música romàntica de fons descarregada automàticament via Freesound.org API v2** (150 registres repartits en 5 CSVs).

3. CANALITZACIÓ 1: CARROUSELS D'IMATGES (generate_and_send_couples.py)
-------------------------------------------------------------------------------
- Canvas: 1080 x 1080 píxels (Format quadrat 1:1), JPEG qualitat=95.
- Estructura: 6 diapositives (Portada + 5 preguntes o enunciats de test).
- Fons: Generat via Google AI Studio (Imagen 3: `imagen-3.0-generate-002`) o Unsplash High-Res API com a fallback.
- Filtre Retro 35mm: Baixada de contrast (0.85), transformació de matriu de color vintage (Sepia càlid) i foscor (0.42) amb marc negre exterior arrodonit (radi=60, margin=28) integrat per màscara de difuminat (blur_r=10).
- Fonts: Playfair Display per als títols/preguntes i Poppins Medium per al footer (`coupleforms`).
- Font de dades: Intercala automàticament entre `posts.csv` i `posts_test.csv` registrant l'estat a `next_post_type.txt`.

-------------------------------------------------------------------------------
4. CANALITZACIÓ 2: VÍDEOS / REELS / TIKTOKS (generate_and_send_reels.py)
-------------------------------------------------------------------------------
- Canvas de vídeo: 1080 x 1920 píxels (Format vertical 9:16), H.264 MP4 a 24 fps amb pista d'àudio AAC.
- Estètica del marc: Fons negre pur (`ColorClip`) amb vídeo retallat exactament a un quadrat centrat de 1080x1080 a Y=420. Barres superiors i inferiors 100% negres opaques.
- Font de Vídeo de Fons: Pexels Video API (`https://api.pexels.com/videos/search`), filtrat per alta resolució (`min_width=1080`, `min_height=1080`) i cerques de paisatges naturals ("scenic nature landscape", "peaceful ocean sunset", "calm forest trees", etc.).
- **Música de Fons Romàntica (Freesound.org API v2)**: 
  - Utilitza la clau d'API `FREESOUND_API_KEY` per consultar l'endpoint `https://freesound.org/apiv2/search/text/`.
  - Cerca automàtica de pistes d'alta qualitat ("romantic piano soft", "soft acoustic guitar romantic", "peaceful piano romance", etc.) filtrant durades de 10 a 120 segons.
  - Descarrega la previsualització MP3 en alta definició (`preview-hq-mp3`).
  - processament amb MoviePy: Reducció de volum al 25% (`volumex(0.25)`), ajustament de durada (bucle si és curta o retallada si és llarga) i fade-out d'àudio de 0.8s al final.
- Engine de Renderització: PIL (Pillow) genera capes PNG transparents amb el marc retro, text centrat i ombra fosca darrere de cada lletra (`draw_text_centered_with_shadow`) per garantir llegibilitat sobre qualsevol fons de vídeo. MoviePy ensambla les capes i l'àudio.

Tipus de Reels i Esquema de CSVs (Rotació automàtica o selecció via `FORCE_TYPE`):
1. `type1` (videos/video_phrases.csv - 100 posts): Frase d'amor central única (8 segons).
   Schema: `Video_ID, Phrase, Status`
2. `type2` (videos/video_questions.csv - 30 posts): Carousel de 3 preguntes seqüencials (14 segons).
   Schema: `Video_ID, Title, Question_1, Question_2, Question_3, Status`
3. `type3` (videos/video_tests.csv - 30 posts): Test A/B ràpid amb pregunta central i opcions fixes "A) You" / "B) Me" (9 segons).
   Schema: `Video_ID, Question, Status`
4. `type4` (videos/video_povs.csv - 30 posts): POV o nota poètica de frase única fixa (10 segons).
   Schema: `Video_ID, Phrase, Status`
5. `type5` (videos/video_checklists.csv - 30 posts): Checklist de 4 punts animats amb guions `-` (12 segons).
   Schema: `Video_ID, Title, Item_1, Item_2, Item_3, Item_4, Status`

5. MODES D'EXECUCIÓ, TEST MODE I TELEGRAM INTEGRATION
-------------------------------------------------------------------------------
Tots dos scripts incorporen la configuració per entorn de `TEST_MODE`:

- Si `TEST_MODE = True`:
  - S'omet la publicació a la xarxa social via Buffer.
  - S'envia el contingut directament a Telegram via Telegram Bot API per a la seva revisió:
    - Carrousels: Envia l'àlbum de les 6 diapositives via `sendMediaGroup`.
    - Reels: Envia el fitxer de vídeo `.mp4` amb àudio via `sendVideo`.
  - Es marca la fila com a 'Done' al CSV i es fa commit/push automàtic amb `git pull --rebase` a Git per mantenir la persistència de dades.

- Si `TEST_MODE = False`:
  - Publica automàticament a través de Buffer GraphQL API.
  - Envia confirmació i còpia del mitjà a Telegram.
  - Actualitza el CSV i fa commit/push a Git.

6. VARIABLES D'ENTORN I SECRETS DE GITHUB
-------------------------------------------------------------------------------
- `PEXELS_API_KEY`: Clau d'API de Pexels per a la descàrrega de vídeos de fons HD.
- `FREESOUND_API_KEY`: Clau d'API de Freesound.org v2 per a la descàrrega de pistes de música romàntica.
- `TELEGRAM_BOT_TOKEN`: Token del bot de Telegram.
- `TELEGRAM_CHAT_ID`: ID del xat/canal de Telegram on es reben les proves/revisions.
- `GEMINI_API_KEY`: Clau de Google AI Studio per a la generació d'imatges via Imagen 3.
- `BUFFER_ACCESS_TOKEN`: Token d'accés de Buffer per a la publicació automàtica.
- `GITHUB_TOKEN`: Proporcionat automàticament per GitHub Actions (`permissions: contents: write`).
