1. PROPÒSIT DEL PROJECTE I ARQUITECTURA GENERAL
-------------------------------------------------------------------------------
CoupleForms és una canalització d'automatització d'extrem a extrem (End-to-End Content Pipeline) desenvolupada en Python 3.10 i integrada amb GitHub Actions. 

El seu objectiu és la generació automàtica i publicació de contingut de doble format enfocat al nínxol de parelles ("Couples") per a Instagram i TikTok, dirigint el tràfic cap a la plataforma web `formfriends.com`:

1. Carrousels d'Imatges (1080x1080, 6 slides): Estil retro 35mm amb preguntes profundes i tests de parella (100 registres a `posts.csv` i `posts_test.csv`). Publicació directa i immediata a TikTok i Instagram via **Zernio API v1**.
2. Vídeos / Reels / TikToks (1080x1920, 9:16): Fons de paisatges naturals HD de Pexels, canviant cada ~4s amb transicions de fosa a negre, un marc quadrat retro centrat (1080x1080 a Y=420), contingut dinàmic llegible amb ombra de text i música romàntica de fons descarregada automàticament via **Freesound.org API v2** (150 registres repartits en 5 CSVs).

3. CANALITZACIÓ 1: CARROUSELS D'IMATGES (generate_and_send_couples.py)
-------------------------------------------------------------------------------
- Canvas: 1080 x 1080 píxels (Format quadrat 1:1), JPEG qualitat=95.
- Estructura: 6 diapositives (Portada + 5 preguntes o enunciats de test).
- Fons: Generat via Google AI Studio (Imagen 3: `imagen-3.0-generate-002`) o Unsplash High-Res API com a fallback.
- Filtre Retro 35mm: Baixada de contrast (0.85), transformació de matriu de color vintage (Sepia càlid) i foscor (0.42) amb marc negre exterior arrodonit (radi=60, margin=28) integrat per màscara de difuminat (blur_r=10).
- Fonts: Playfair Display per als títols/preguntes i Poppins Medium per al footer (`coupleforms`).
- Font de dades: Intercala automàticament entre `posts.csv` i `posts_test.csv` registrant l'estat a `next_post_type.txt`.
- Hosting d'imatges: Pujada automàtica de les diapositives via FTP (`formfriends.com/public_slides/`) o fallback a Raw GitHub URLs per tal que Zernio pugui accedir a les URLs públiques directes.

-------------------------------------------------------------------------------
4. CANALITZACIÓ 2: VÍDEOS / REELS / TIKTOKS (generate_and_send_reels.py)
-------------------------------------------------------------------------------
- Canvas de vídeo: 1080 x 1920 píxels (Format vertical 9:16), H.264 MP4 a 24 fps amb pista d'àudio AAC.
- Estètica del marc: Fons negre pur (`ColorClip`) amb vídeo retallat exactament a un quadrat centrat de 1080x1080 a Y=420. Barres superiors i inferiors 100% negres opaques.
- Font de Vídeo de Fons: Pexels Video API (`https://api.pexels.com/videos/search`), filtrat per alta resolució (`min_width=1080`, `min_height=1080`) i cerques de paisatges naturals.
- Música de Fons Romàntica (Freesound.org API v2): Cerca automàtica de pistes d'alta qualitat, descàrrega de `preview-hq-mp3`, reducció de volum al 25% (`volumex(0.25)`), ajustament de durada i fade-out d'àudio de 0.8s.
- Engine de Renderització: PIL (Pillow) genera capes PNG transparents amb el marc retro, text centrat i ombra fosca (`draw_text_centered_with_shadow`). MoviePy ensambla les capes i l'àudio.

5. ESPECIFICACIÓ TÈCNICA DE L'API DE ZERNIO (TIKTOK + INSTAGRAM)
-------------------------------------------------------------------------------
Endpoint de publicació: `POST https://zernio.com/api/v1/posts`

Normes i requeriments estrictes del Payload JSON per a evitar errors de publicació:

1. Estructura de Plataformes (`platforms`):
   - Ha de ser una llista d'objectes (NO matrius de strings simples).
   - Cada objecte ha de contenir `platform` ("tiktok" o "instagram") i el seu respectiu `accountId`.
   - Permet definir `content` personalitzat per plataforma.

2. Gestió de Límit de Caràcters (TikTok Photo Mode Cap):
   - TikTok Photo Mode utilitza el contingutcom a títol del carrousel i imposa un LÍMIT DIRECTE DE 90 CARÀCTERS.
   - El camp `content` per a TikTok s'ha de retallar a un màxim de 90 caràcters (`title[:87] + "..."`).
   - Instagram pot rebre el contingut complet amb descripció i hashtags (`title + "\n\n" + caption`).

3. Format d'Imatges (`mediaItems`):
   - Requereix un array d'objectes amb l'estructura `[{"type": "image", "url": "https://..."}]`.
   - Per a compatibilitat amb la API REST i SDKs de Zernio, s'envien les claus `mediaItems` i `media_items`.

4. Activació d'Àudio Automàtic i Permisos de TikTok:
   - TikTok exigeix declaració explícita de consentiment per aplicar so automàtic.
   - S'han d'incloure els paràmetres:
     - `auto_add_music` / `autoAddMusic`: True
     - `privacy_level`: "PUBLIC_TO_EVERYONE"
     - `media_type`: "photo"
     - `photo_cover_index`: 0
     - `content_preview_confirmed`: True
     - `express_consent_given`: True

5. Publicació Immediata vs Drafts:
   - S'ha d'incloure `"publishNow": True` (o `publish_now: True`). Si no s'inclou, Zernio desa el post com a esborrany i no el publica.

6. Timeout de Xarxa:
   - La petició HTTP requereix un `timeout=120` segons. Temps inferiors (com 30s) poden produir un `Read timed out` a Python mentre Zernio processa les imatges a ambdues plataformes.

-------------------------------------------------------------------------------
6. EXEMPLE PRÀCTIC DE CODI (IMPLEMENTACIÓ ZERNIO EN PYTHON)
-------------------------------------------------------------------------------
Aquest és el fragment exacte de codi utilitzat a `generate_and_send_couples.py`:

```python
import requests

def post_to_zernio(api_key, tiktok_account_id, instagram_account_id, image_urls, title, caption):
    """
    Publica un carrousel d'imatges immediatament a TikTok i Instagram via Zernio API,
    respectant el límit de 90 caràcters de TikTok i activant la música automàtica.
    """
    if not image_urls:
        print("❌ Error: La llista d'URLs d'imatges està buida.")
        return False

    zernio_url = "[https://zernio.com/api/v1/posts](https://zernio.com/api/v1/posts)"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }

    clean_title = title.strip()

    # 1. Ajust de text per al límit de 90 caràcters de TikTok Photo Mode
    if len(clean_title) > 90:
        tiktok_content = clean_title[:87] + "..."
    else:
        tiktok_content = clean_title

    # 2. Text complet per a Instagram (Títol + Descripció + Hashtags)
    instagram_content = f"{clean_title}\n\n{caption}"

    # 3. Format d'objectes multimèdia
    media_items = [{"type": "image", "url": url} for url in image_urls]

    # 4. Paràmetres complets de configuració i consentiment per a TikTok
    tiktok_settings_payload = {
        "privacy_level": "PUBLIC_TO_EVERYONE",
        "allow_comment": True,
        "media_type": "photo",
        "photo_cover_index": 0,
        "description": instagram_content,
        "auto_add_music": True,
        "autoAddMusic": True,
        "content_preview_confirmed": True,
        "express_consent_given": True
    }

    # 5. Payload global
    payload = {
        "content": tiktok_content,
        "media_items": media_items,
        "mediaItems": media_items,
        "platforms": [
            {
                "platform": "tiktok",
                "accountId": tiktok_account_id,
                "content": tiktok_content,
                "tiktok_settings": tiktok_settings_payload,
                "tiktokSettings": tiktok_settings_payload
            },
            {
                "platform": "instagram",
                "accountId": instagram_account_id,
                "content": instagram_content
            }
        ],
        "tiktok_settings": tiktok_settings_payload,
        "tiktokSettings": tiktok_settings_payload,
        "publish_now": True,
        "publishNow": True
    }

    try:
        # Timeout de 120 segons per evitar Read timed out durant el processament doble
        response = requests.post(zernio_url, headers=headers, json=payload, timeout=120)
        if response.status_code in (200, 201):
            print("✅ Carrousel enviat i publicat amb èxit a Zernio (TikTok + Instagram)!")
            return True
        else:
            print(f"❌ Error en publicar a Zernio ({response.status_code}): {response.text}")
            return False
    except Exception as e:
        print(f"⚠️ Excepció en comunicar amb Zernio: {e}")
        return False
